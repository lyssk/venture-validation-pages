What it does

  • A visual timeline of today with a line showing the current time.
  • Plan ahead: go to tomorrow or any date, and switch between day, week and month views.
  • Drag a task to set its start time. It snaps to 15 minutes. In the week view you can drag a task onto any day.
  • Repeating tasks: every day, every weekday, every week, every month or every year, including all-day ones like birthdays.
  • Optional reminders: a Chrome notification when a task starts, or a few minutes before. Chrome needs to be running.
  • A search box that uses your default search engine and opens results in a new tab, plus optional rows for your most visited sites and your bookmarks bar. Chrome asks for each permission only if you turn the row on.
  • Import events from a Google Calendar or Outlook export file (.ics). A one-time, read-only snapshot, not live sync.
  • No account. Your plan stays in your browser (chrome.storage.local); no analytics in the extension, and it makes no network requests of its own.
  • Keyboard friendly, with light and dark mode.
