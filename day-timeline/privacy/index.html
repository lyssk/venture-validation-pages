Privacy policy: Day Timeline – New Tab Planner (Chrome extension)

Effective 2026-11-03; updated 2026-11-06 for version 0.2.0 (sections marked "0.2.0" are new). Applies to the browser extension only. The product web page has its own privacy notice.

Website update, 2026-11-06: the product web page records basic visit events again (page, referrer, campaign tags, a random session ID, browser type; no cookies) and, only if you choose to leave it, your email for Pro launch news. This data is stored in a new database (Supabase, EU, Frankfurt) created on 2026-11-06; the page's own privacy notice gives the details. Between 2026-11-05 and 2026-11-06 the web pages recorded nothing, and data stored before 2026-11-05 was deleted with our old database. This does not change anything below about the extension, which still collects no data.

Summary

The extension collects no data. We (Venture Lab) receive nothing from it: no account, no analytics, no tracking, no ads, no remote code.

What the extension stores, and where

  • Your tasks (name, duration, date, start time or "all day", and for repeating tasks the repeat rule and any days you changed or skipped), your settings (theme, view, week start, which new tab rows are shown, reminder settings), and, if you import one, the contents and file name of the .ics calendar file you choose.
  • 0.2.0: if reminders are on, a short list of the reminders already shown, so none is shown twice. Entries are deleted after 3 days.
  • 0.2.0: when you first open version 0.2.0, a one-time copy of your tasks from version 0.1.x (dt_backup_v1), kept as a safety net for the update. It is never sent anywhere.
  • All of this is stored only in your browser, using Chrome's local extension storage (chrome.storage.local). It is not synced and never sent to us or anyone else.
  • Removing the calendar in the extension deletes the calendar data; deleting a task removes that task; uninstalling the extension deletes everything.

Optional bookmarks display (version 0.1.1)

If you click "Show my bookmarks here" (or, from 0.2.0, tick "Bookmarks bar row" in Settings), Chrome asks you to allow the optional bookmarks permission. With it, the extension reads the items on your bookmarks bar inside your browser and shows them as links on the new tab. It never changes, copies or sends your bookmarks anywhere; it only remembers (in chrome.storage.local) that you turned the row on. Clicking "Hide bookmarks" (or unticking it in Settings) hides the row and removes the permission. If you don't turn it on, the extension has no access to your bookmarks.

Optional most visited sites (0.2.0)

If you tick "Most visited sites" in Settings, Chrome asks you to allow the optional topSites permission ("Read a list of your most frequently visited websites"). With it, each time the new tab opens the extension reads Chrome's list of your most visited sites inside your browser and shows them as links. The list is not stored and never sent anywhere. Unticking it hides the row and removes the permission. If you don't turn it on, the extension has no access to this list.

Optional reminders (0.2.0)

If you tick "Notify me when a task starts" in Settings, Chrome asks you to allow the optional notifications permission. The extension's background service worker then uses Chrome's alarms API to wake up at your next task's start time (or the 5 to 30 minutes before that you chose) and shows a notification with the task's title and time. You can also include events from your imported .ics file. Reminders are worked out from the data stored in your browser and shown by Chrome on your device; nothing is sent to us or anyone else. Unticking it stops reminders and removes the permission. The alarms permission itself does not show a warning and is not used while reminders are off.

Search box (0.2.0)

The search box on the new tab sends what you type to your own default search engine (the one set in Chrome's settings), using Chrome's search API, and opens the results in a new tab. The extension does not read, store or change your search settings or your searches; the search engine you use handles your query under its own privacy policy. You can hide the search box in Settings.

Network requests

The extension makes no network requests of its own. (Clicking one of your bookmarks or most visited sites simply opens that site in the tab, as Chrome's own new tab page does, and a search you type opens your default search engine.) Calendars are imported only from a file you choose on your device, and the file is read inside your browser. The extension has no host permissions and no content scripts, so it cannot read or change the web pages you visit.

Sharing and sale

We don't sell, share or transfer user data, because we don't receive any. We don't use it for advertising, credit-worthiness or any purpose other than showing your day in the new tab.

Google APIs

This version does not use Google APIs or Google sign-in, and does not connect to Google Calendar, Outlook or any other online calendar. (The search box uses Chrome's built-in search API, which is not a Google API.)
